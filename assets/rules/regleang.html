Brick Shooter

Rules :

Français


GOAL :

Line at least 3 blocks up of the same color to make them disappear.

The round ends when all the fixed blocks (placed at the beginning of the round) have disappeared.

The game is lost if the zone is filled ; there is no possibility of acquiring more points.


How To Play :

● click on a movable block (outside the playing area) to make it move forward.

● the block will move in the indicated direction and then stop when it reaches another block ;
if the block in front of it disappears, it will start moving again.

● the block will not be able to change direction.
